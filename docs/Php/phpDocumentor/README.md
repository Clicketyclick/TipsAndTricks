# phpDocumentor

## Install

Download phpDocumentor
```
wget https://phpdoc.org/phpDocumentor.phar
```

Install
```
"C:\Program Files\php\phar.phar.bat" extract -f phpDocumentor.phar
```

alias
```
"C:\Program Files\php\php.exe" "C:\Program Files\php\pharcommand.phar"  extract -f phpDocumentor.phar
```


Run
```
"C:\Program Files\php\phar.phar.bat" extract -f phpDocumentor.phar
```
alias
```
phpdoc.cmd
```
